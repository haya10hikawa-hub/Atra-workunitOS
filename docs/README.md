# Repository documentation

Use [`PRODUCT_STATE.md`](../PRODUCT_STATE.md) for the current product state, then
[`docs/current/`](current/) for current repository authority. Research belongs in
[`docs/research/`](research/); frozen V0 product direction belongs in
[`docs/archive/v0/`](archive/v0/). Non-product historical technical, phase, and
audit records belong in [`docs/legacy/`](legacy/).
