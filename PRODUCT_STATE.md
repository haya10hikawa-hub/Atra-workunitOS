## Meaning

Atra V0 remains frozen as historical product work.

The current exploration does not restore the V0 roadmap. V0 concepts remain historical hypotheses or reusable technical assets unless explicitly re-derived from evidence.

The reusable V0 capability currently retained is upstream context reconstruction: scattered information may be used to form the intent for a concrete work item.

The current core hypothesis is narrower:

Intent
→ Delegation
→ Change
→ Evidence
→ Fulfillment

Atra should preserve the relation between what was intended, who or what was delegated the work, what actually changed, what evidence came back, and how much of the intent was satisfied.

## Validation rule

The initial validation domain is Software Engineering because the product can be dogfooded against real AI-assisted coding work.

The hypothesis survives only if Prompt / Issue intent can be mapped to Git-tracked changes and returned evidence in a way that materially reduces review effort or detects intent drift earlier.

If that value does not appear in real use, this direction is rejected.
